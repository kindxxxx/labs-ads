# G. Jonathan the Poet

## Условие

Стихотворение — список из `N` слов. Нужен **сдвиг влево на `K`**: первые `K` слов уезжают в конец. Внутри частей порядок не меняется.

```
w1 w2 … wK | wK+1 … wN
           ↓
wK+1 … wN | w1 w2 … wK
```

Всегда `1 ≤ K < N`, список не пустой.

Пример: `the show must go on`, `K=2` → `must go on the show`

## Алгоритм

Разрезаем цепочку после `K`-го слова.

1. Дойти до `K`-го узла (он станет хвостом первой части).
2. Новая голова = его `next` (начало второй части).
3. Обрезать: `K.next = None`.
4. Дойти до конца второй части и прицепить туда старую голову.

```
the → show → must → go → on     K=2
             ↑ режем после show
must → go → on → the → show
```

На пальцах: «первые K вагонов отцепили и прицепили в хвост».

## Код

- `rotate_left(head, k)`:
  - `for _ in range(k - 1)` — стоим на `k`-м узле (из головы `k-1` шаг).
  - `new_head = cur.next` — запомнили, откуда начнётся ответ.
  - `cur.next = None` — разрезали.
  - `tail = new_head`, идём `while tail.next` до конца второй части.
  - `tail.next = head` — старое начало стало хвостом.
  - `return new_head`
- Слова кладём в `Node` как строки, печатаем через пробел.
