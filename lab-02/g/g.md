# G. Jonathan the Poet

## Условие

Стихотворение — односвязный список из `N` слов. Нужен **циклический сдвиг влево на `K`**: первые `K` слов уезжают в конец, порядок внутри частей не меняется.

```
w1 w2 … wK | wK+1 … wN
         ↓
wK+1 … wN | w1 w2 … wK
```

- `1 ≤ K < N ≤ 10^5` — сдвиг всегда настоящий, список не пустой

## Идея

Найти узел номер `K` (1-индексация). Он станет **новым хвостом первой части**.

- новая голова = `K.next`
- `K.next = None` — разрезаем список
- идём до конца второй части и прицепляем старую голову

```
the -> show -> must -> go -> on     K=2
               ↑ разрез после show
must -> go -> on -> the -> show
```

## Алгоритм

1. Построить список слов.
2. Дойти до `K`-го узла.
3. `new_head = cur.next`, затем `cur.next = None`.
4. Дойти до хвоста второй части, `tail.next = old_head`.
5. Вывести слова от `new_head`.

## Сложность

- время: `O(N)`
- память: `O(1)` дополнительно

## Примеры

`N=5 K=2`: `the show must go on` → `must go on the show`  
`N=5 K=3`: `another one bites the dust` → `the dust another one bites`
