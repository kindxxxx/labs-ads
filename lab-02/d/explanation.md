# D. Reverse the Linked List

## Условие

Плейлист — односвязный список: у песни есть только стрелка `next` вперёд, назад идти нельзя. Нужно **развернуть** список (переставить стрелки).

Вход: `n`, потом `n` чисел. Выход: числа в обратном порядке через пробел.

Пример: `1 2 3 4 5` → `5 4 3 2 1`

`n` до 200000, поэтому рекурсию нельзя — стек лопнет.

## Алгоритм

Три пальца: `prev` (предыдущий), `cur` (текущий), `nxt` (следующий, чтобы не потерять).

Для каждого узла:

1. Запомнить, кто был следующим: `nxt = cur.next`.
2. Повернуть стрелку назад: `cur.next = prev`.
3. Сдвинуть пальцы: `prev = cur`, `cur = nxt`.

Когда `cur` стал `None`, новая голова — `prev` (бывший хвост).

```
было:  1 → 2 → 3 → 4 → 5
стало: 1 ← 2 ← 3 ← 4 ← 5
голова теперь 5
```

На одном узле: стрелку повернули на `None`, он и остаётся головой.

## Код

- `reverse_list(head)` возвращает **новую** голову.
- Старт: `prev = None`, `cur = head`.
- `nxt` обязателен: без него, повернув `next`, потеряем остаток списка.
- Возвращаем `prev`, не `cur` (`cur` уже `None`).
- Сбор списка через `dummy`, печать обычным проходом.
