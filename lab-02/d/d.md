# D. Reverse the Linked List

## Условие

Плейлист — **односвязный** список: у песни есть только `next`, назад идти нельзя. Нужно развернуть список, переставив указатели `next`.

- `1 ≤ n ≤ 2·10^5`

## Идея

Итеративный разворот тремя указателями: `prev`, `cur`, `nxt`.

Для текущего узла запоминаем, кто был следующим, а `next` поворачиваем на предыдущий.

```
исходно:  1 -> 2 -> 3 -> 4 -> 5
стало:    1 <- 2 <- 3 <- 4 <- 5
голова:   5
```

Рекурсию здесь лучше не использовать: при `n = 2·10^5` будет переполнение стека.

## Алгоритм

```
prev = None
cur = head
пока cur не None:
    nxt = cur.next
    cur.next = prev
    prev = cur
    cur = nxt
новый head = prev
```

1. Собрать список.
2. Развернуть указатели.
3. Вывести значения от новой головы к хвосту.

## Сложность

- время: `O(n)` — один проход
- память: `O(1)` дополнительной (кроме самих узлов)

## Пример

`1 2 3 4 5` → `5 4 3 2 1`  
Один элемент `-7` остаётся `-7`.
