# C. Database

## Условие

Список имён сломался: одинаковые имена стоят **подряд** (не вразброс). Нужно оставить только **первое** имя из каждой такой группы. Порядок не менять.

Вход: `N`, потом `N` имён по одному в строке.  
Выход: сколько имён осталось, затем сами имена по одному в строке.

Регистр важен: `Aa` и `aA` — разные имена. `N` до 100000.

Пример:

```
Alice
Dana
Dana
Dana
Bob
```

→ остаётся `Alice`, `Dana`, `Bob`.

## Алгоритм

Идём по цепочке. Смотрим на текущего и на следующего.

- Если имена **одинаковые** — выкидываем следующего (`cur.next = cur.next.next`). Сами **не двигаемся**: вдруг дубликатов ещё пачка.
- Если имена **разные** — это уже новая группа, шагаем вперёд (`cur = cur.next`).

```
Alice → Dana → Dana → Dana → Bob
Alice → Dana ──────────────→ Bob
```

Шаги:

1. Собрать односвязный список имён.
2. Проредить подряд идущие копии.
3. Посчитать оставшихся и напечатать.

## Код

- `unique_consecutive(head)` — весь смысл задачи.
- Цикл `while cur and cur.next`: есть кого сравнивать.
- `if cur.val == cur.next.val` — сосед-двойник, режем стрелку, `cur` остаётся на месте.
- `else` — соседи разные, идём дальше.
- `dummy` снова нужен только чтобы удобно собрать список из `N` строк.
- Вывод: сначала `len(out)`, потом имена через перевод строки.
