# C. Database

## Условие

Список студентов сломался: одинаковые имена стоят **подряд** (не разбросаны по списку). Нужно оставить только **первую** запись из каждой группы одинаковых соседей, порядок не менять.

- `1 ≤ N ≤ 10^5`
- имя — до 20 латинских букв, регистр важен (`Aa` ≠ `aA`)

## Идея

Это классическое удаление дубликатов из **отсортированного / сгруппированного** связного списка.

Идём по списку. Если текущий узел и следующий имеют одно и то же имя — выкидываем следующий. Если имена разные — просто идём дальше.

```
Alice -> Dana -> Dana -> Dana -> Bob
Alice -> Dana ---------------> Bob
```

## Алгоритм

1. Построить односвязный список имён.
2. Пока есть следующий узел:
   - если `cur.val == cur.next.val` → `cur.next = cur.next.next` (не двигаем `cur`, вдруг дубликатов ещё больше)
   - иначе `cur = cur.next`
3. Вывести количество оставшихся имён и сами имена по одному в строке.

## Сложность

- время: `O(N)` — каждый узел смотрим константное число раз
- память: `O(N)`

## Пример

```
Alice
Dana
Dana
Dana
Bob
```

Группы: `[Alice]`, `[Dana, Dana, Dana]`, `[Bob]` → оставляем `Alice Dana Bob`.

Второй пример: `wow` и `kek` разные → оба остаются.
