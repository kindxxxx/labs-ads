# I. Doubly linked list

## Условие

Нужен **двусвязный** список книг и команды. Последняя всегда `exit`.

| команда | что делает | печать |
|---------|------------|--------|
| `add_front title` | вставить в начало | `ok` |
| `add_back title` | вставить в конец | `ok` |
| `erase_front` | удалить первую | название или `error` |
| `erase_back` | удалить последнюю | название или `error` |
| `front` / `back` | посмотреть край | название или `error` |
| `clear` | очистить | `ok` |
| `exit` | конец | `goodbye` |

Пустой список: `erase_*`, `front`, `back` → `error`, список не трогаем. `clear` и `exit` на пустом ок.

## Алгоритм

У узла две стрелки: `prev` (назад) и `next` (вперёд). Плюс помним `head` (первый) и `tail` (последний).

```
нет ← A ⇄ B ⇄ C → нет
      ↑head    ↑tail
```

Из-за `head` и `tail` все операции с концами за один шаг, без пробежки по всему списку.

**add_front:** новый узел смотрит `next` на старую голову. Старая голова смотрит `prev` на нового. Новый становится `head`. Если список был пуст — он же и `tail`.

**add_back:** зеркало с хвостом.

**erase_front:** запомнить название головы. Голова = `head.next`. У новой головы `prev = None`. Если никого не осталось — `tail = None`.

**erase_back:** зеркало.

**clear:** просто `head = tail = None`.

## Код

- `Node`: `val`, `prev`, `next`.
- Всегда чиним **две** стороны: и `next` соседа, и `prev`. Иначе цепочка порвётся в одну сторону.
- Пустой список: `head is None` (тогда и `tail` тоже `None`).
- Ответы копим в `out`, в конце печатаем разом — так быстрее при 100000 команд.
- `front`/`back` список не меняют, только смотрят.
