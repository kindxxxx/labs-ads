# J. Zoro and Seven Sword Style

## Условие

Нужно восстановить операции односвязного списка. Позиции **с нуля**. Команда `0` завершает программу.

| код | операция | что делает |
|-----|----------|------------|
| 1 | `insert x p` | вставить значение `x` на позицию `p` (`0 ≤ p ≤ длине`) |
| 2 | `remove p` | удалить узел на позиции `p` |
| 3 | `print` | все значения через пробел; если список пуст — `-1` |
| 4 | `replace p1 p2` | вынуть узел с `p1` и вставить на `p2` (позиция `p2` считается **уже после удаления**) |
| 5 | `reverse` | развернуть весь список |
| 6 | `cyclic_left x` | циклический сдвиг влево на `x` |
| 7 | `cyclic_right x` | циклический сдвиг вправо на `x` |

Для сдвигов `x` меньше длины списка.

Сабтаски просят все операции за `O(N)` или быстрее.

## Идея

Односвязный список + фиктивных узлов нет, функции возвращают новую голову.

**insert / remove.** Дойти до узла `p-1` и поправить один указатель `next`. Если `p = 0` — меняется голова.

**replace.** Снять значение с `p1`, удалить этот узел, вставить то же значение на `p2` уже в укороченный список.

Пример: `[a, b, c, d]`, `p1=1`, `p2=2`  
сняли `b` → `[a, c, d]` → вставили на позицию 2 → `[a, c, b, d]`

**reverse.** Три указателя `prev, cur, nxt` — как в задаче D.

**cyclic_left x.** Первые `x` узлов уезжают в конец:

1. дойти до `x`-го узла (он станет хвостом префикса)
2. новая голова — следующий за ним
3. обрезать префикс, хвост суффикса прицепить к старой голове

`1 2 3 4 5`, влево на 2 → `3 4 5 1 2`

**cyclic_right x.** Последние `x` узлов едут в начало. Это то же самое, что сдвиг влево на `n - x`.

`1 2 3 4 5`, вправо на 2 → `4 5 1 2 3` = влево на 3.

## Сложность

каждая операция `O(N)` — один-два прохода по списку. Этого хватает на все сабтаски формулировки.

## Ввод

Каждая строка начинается с номера команды. Числа команды идут в той же строке. Пока не встретили `0`.
