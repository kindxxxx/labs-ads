# A. One-time guests

## Условие

Идёт поток букв. После **каждой** новой буквы нужно сказать: какая буква сейчас самая левая и встретилась **ровно 1 раз**. Если такой нет — `-1`.

Пример: `a a b c` → ответы `a -1 b b`

- несколько тестов `T`
- в тесте сначала длина, потом буквы через пробел

## Алгоритм

Думаем так: у нас очередь претендентов «я пока уникальный».

На каждую новую букву `ch`:

1. Увеличиваем счётчик: сколько раз эта буква уже была.
2. Если буква пришла **впервые** — ставим её в **конец очереди**.
3. С **начала** очереди выкидываем всех, у кого счётчик уже больше 1 (они больше не уникальные).
4. Ответ — первый в очереди. Если очередь пустая — `-1`.

Почему это работает: очередь хранит буквы **в порядке появления**. Первый, кто ещё уникален, и есть самый левый.

Пример по шагам (`a a b c`):

| пришла | счётчики     | очередь | ответ |
|--------|--------------|---------|-------|
| a      | a=1          | a       | a     |
| a      | a=2          | пусто   | -1    |
| b      | a=2, b=1     | b       | b     |
| c      | a=2, b=1, c=1| b, c    | b     |

## Код

- `Counter` — словарь «буква → сколько раз».
- `deque` — очередь: `append` в конец, `popleft` из начала.
- `cnt[ch] == 1` — первый раз увидели, кладём в очередь.
- `while q and cnt[q[0]] > 1` — голова уже повторялась, выкидываем.
- `q[0] if q else '-1'` — есть претендент или нет.

Главное: не сканировать весь поток заново после каждой буквы. Каждая буква в очередь кладётся и выкидывается **не больше одного раза**.
