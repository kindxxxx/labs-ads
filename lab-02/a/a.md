# A. One-time guests

## Условие

Идёт поток строчных латинских букв. После каждой новой буквы нужно вывести **первую (самую левую)** букву, которая пока встретилась **ровно один раз**. Если таких нет — вывести `-1`.

- `T` тестов (`1 ≤ T ≤ 200`)
- в тесте длина потока `N` (`1 ≤ N ≤ 500`)

## Идея

Нужно быстро отвечать: «кто сейчас первый уникальный?»

Храним:

1. **счётчик** — сколько раз каждая буква уже пришла;
2. **очередь** — буквы в порядке первого появления, которые ещё претендуют на «уникальных».

Когда буква приходит **в первый раз** — кладём её в конец очереди.  
Когда буква повторяется — она больше не уникальная. С начала очереди выкидываем всех, у кого счётчик уже больше 1.

Тогда первый элемент очереди — и есть ответ. Если очередь пустая — `-1`.

Это тот же смысл, что идти слева направо по текущему префиксу и искать первую букву со счётчиком 1, только без повторного полного скана каждый раз.

## Алгоритм

Для каждой буквы `ch` в потоке:

1. `cnt[ch] += 1`
2. если `cnt[ch] == 1` — добавить `ch` в очередь
3. пока очередь не пуста и `cnt[очередь.front] > 1` — убрать голову очереди
4. ответ: голова очереди или `-1`

## Сложность

- время: `O(N)` на тест — каждая буква добавляется и удаляется из очереди не больше одного раза
- память: `O(1)` по алфавиту (26 букв) + очередь

## Пример

Поток: `a a b c`

| после | счётчики        | очередь | ответ |
|-------|-----------------|---------|-------|
| a     | a:1             | a       | a     |
| a a   | a:2             | пусто   | -1    |
| a a b | a:2 b:1         | b       | b     |
| a a b c | a:2 b:1 c:1   | b, c    | b     |

Второй пример: `a d b c a a` → `a a a a d d`  
(после второго `a` буква `a` перестаёт быть уникальной, первой уникальной становится `d`)
