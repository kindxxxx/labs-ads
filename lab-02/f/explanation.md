# F. Merge Two Sorted Lists

## Условие

Даны два списка, **уже отсортированных по неубыванию**. Нужно слить в один такой же.

Важно: не создавать новые коробочки с теми же числами, а **перецепить старые** стрелками `next`.

Вход: две строки. В каждой сначала длина, потом числа. Длина может быть 0.

Выход: слитый список через пробел. Оба пустые → пустая строка.

Пример: `1 3 5` и `2 4 6` → `1 2 3 4 5 6`

## Алгоритм

Как слияние в сортировке: два указателя `a` и `b`. Кто меньше — того и прицепляем.

Чтобы не мучиться с «кто будет первой головой», ставим фальшивый узел `dummy`. К нему цепляем результат, а настоящей головой будет `dummy.next`.

Пока оба списка ещё не кончились:

- если `a.val ≤ b.val` — берём `a`, двигаем `a`
- иначе берём `b`, двигаем `b`

Когда один кончился — прицепляем хвост второго как есть (он уже отсортирован).

```
a: 1 → 3 → 5
b: 2 → 4 → 6
         ↓
   1 → 2 → 3 → 4 → 5 → 6
```

## Код

- `build(vals)` — собирает список из куска строки (числа после длины). `line1[1:]` — всё кроме первого числа (это была длина).
- `Node(int(v))` — значения надо сравнивать как числа, не как строки (`"10"` < `"2"` было бы враньё).
- `merge(a, b)`:
  - `dummy` + `cur` — хвост уже собранного ответа
  - `while a and b` — оба живы
  - после цикла `cur.next = a if a else b` — остаток
  - `return dummy.next`
- Пустой вход: `build([])` вернёт `None`, merge это нормально переживёт.
