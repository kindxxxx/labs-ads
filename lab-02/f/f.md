# F. Merge Two Sorted Lists

## Условие

Два **уже отсортированных по неубыванию** односвязных списка нужно слить в один такой же. Новый список собирается **из старых узлов** — только перестановка `next`, без новых узлов с билетами.

- длины `0 ≤ n, m ≤ 10^5`
- если оба пустые — пустая строка

## Идея

Как merge в merge-sort: два указателя. Кто меньше — того и прицепляем к результату, двигаем этот указатель.

Фиктивный узел `dummy` упрощает код: не надо отдельно обрабатывать первую голову.

```
a: 1 -> 3 -> 5
b: 2 -> 4 -> 6
         ↓
1 -> 2 -> 3 -> 4 -> 5 -> 6
```

Когда один список кончился — прицепляем хвост второго как есть (он уже отсортирован).

## Алгоритм

```
dummy = Node
cur = dummy
пока a и b оба не пусты:
    если a.val ≤ b.val: cur.next = a, a = a.next
    иначе:              cur.next = b, b = b.next
    cur = cur.next
cur.next = a или b (кто остался)
ответ = dummy.next
```

Пустой список: если `n = 0`, узлов нет, голова `None`. Сравнивать `a.val` без проверки нельзя — сначала смотрим, что список не пуст.

## Сложность

- время: `O(n + m)`
- память: `O(1)` дополнительно (dummy не считается частью ответа)

## Примеры

`1 3 5` и `2 4 6` → `1 2 3 4 5 6`  
пустой и `2 4 6` → `2 4 6`  
оба пустые → пустая строка
