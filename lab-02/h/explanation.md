# H. Ragnarok

## Условие

Список из `n` чисел — дни. Нужна **максимальная сумма куска подряд** (непустого).

Пустой кусок брать нельзя. Если все числа отрицательные, ответ — самое большое из них (типа `-1`, а не `0`).

`n ≤ 100`. Пример: `1 2 -1 4 5` → `11` (весь массив).  
`-1 -1 -1` → `-1`.

## Алгоритм (Кадане)

Идём по списку один раз и держим два числа:

- `cur_sum` — лучшая сумма куска, который **заканчивается на сегодня**
- `best` — лучшая сумма среди всех кусков, которые уже видели

Правило на новый день `x`:

- если `cur_sum > 0` — выгоднее **продолжить** кусок: `cur_sum += x`
- если `cur_sum ≤ 0` — прошлый кусок только портит, **начинаем заново** с `x`

Потом `best = max(best, cur_sum)`.

Почему: отрицательный хвост перед нами тянет сумму вниз. Лучше отрезать его и стартовать здесь.

Пример `5 3 -10 5 3 9`:

- `5`, `5+3=8`, `8-10=-2` → дальше лучше начать с `5`
- `5+3+9=17` — это и есть ответ

## Код

- `max_subarray(head)`:
  - старт: `best = cur_sum = head.val` (хотя бы один день взять обязаны)
  - сразу `head = head.next`, дальше цикл по остальным
  - `if cur_sum > 0: cur_sum += head.val else: cur_sum = head.val`
  - если новый `cur_sum` больше `best` — обновляем
- Список всё равно строим через `Node`, хотя по сути это один проход по числам.
