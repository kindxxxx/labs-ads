# H. Ragnarok

## Условие

Хроника — односвязный список из `n` чисел (дни). Нужна **максимальная сумма непустого отрезка подряд идущих дней**.

- `1 ≤ n ≤ 100`
- `-10^4 ≤ a_i ≤ 10^4`
- пустой отрезок брать нельзя: если все дни плохие, ответ — самое большое (наименее отрицательное) число

## Идея

Алгоритм Кадане. Идём по списку один раз и держим:

- `cur_sum` — лучшая сумма отрезка, который **заканчивается на текущем дне**
- `best` — лучшая сумма среди всех уже увиденных отрезков

Правило для `cur_sum`:

- если предыдущая `cur_sum > 0` — выгоднее продолжить отрезок;
- если `cur_sum ≤ 0` — лучше начать новый отрезок с текущего дня (отрицательный префикс только портит сумму).

## Алгоритм

```
best = cur_sum = head.val
для каждого следующего узла x:
    cur_sum = cur_sum + x.val   если cur_sum > 0
              x.val             иначе
    best = max(best, cur_sum)
```

## Сложность

- время: `O(n)`
- память: `O(1)` дополнительно

`n ≤ 100`, поэтому подошёл бы и полный перебор всех отрезков `O(n²)`, но Кадане короче и правильнее по смыслу.

## Примеры

`1 2 -1 4 5` — весь массив, сумма `11`

`-1 -1 -1` — лучший один день, `-1` (не ноль!)

`5 1 2 -10 5 3 9 -5 10 10`:
после `-10` выгоднее начать заново с `5 3 9 -5 10 10` = `32`
