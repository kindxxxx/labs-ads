# B. Kuanyshbek

## Условие

В файл писали два потока по очереди: 1-й, 2-й, 1-й, 2-й, …

Нужны только записи **первого** потока — это нечётные места: 1, 3, 5, …

Сделать через **связный список**: построить цепочку и удалить каждый второй узел.

Вход: `N`, потом `N` чисел. Выход: оставшиеся числа через пробел.

Пример: `1 2 3 4 5` → `1 3 5`

## Алгоритм

Связный список — цепочка коробочек. В коробочке лежит число и стрелка `next` на следующую.

```
1 → 2 → 3 → 4 → 5 → конец
```

Идём по списку. Стоим на текущем узле и **перепрыгиваем через соседа**:

```
cur.next = cur.next.next
```

Сосед пропадает. Потом сами переходим на нового соседа (он как раз следующий нечётный).

```
1 → 2 → 3 → 4 → 5
1 ────→ 3 → 4 → 5     убрали 2
1 ────→ 3 ────→ 5     убрали 4
```

Шаги:

1. Собрать список из входных чисел.
2. Пока у текущего есть следующий — удалить его, сдвинуться дальше.
3. Пройти список и напечатать значения.

## Код

- `Node(val)` — коробочка: `val` и `next`.
- `dummy = Node(0)` — пустой старт. К нему удобно цеплять первый настоящий узел, не думая «а вдруг список пустой». Голова — `dummy.next`.
- `delete_every_second`: цикл `while cur and cur.next`. Сначала `cur.next = cur.next.next` (удалили чётного), потом `cur = cur.next` (перешли на следующего нечётного).
- В конце обычный проход: `while head: печатаем head.val; head = head.next`.
