# E. Delete the Middle Node

## Условие

Список из `n` бегунов, номера с **нуля**: голова — 0, дальше 1, 2, …

Нужно удалить «середину»: узел с номером `n // 2` (деление нацело вниз).

- если `n = 1` — список станет пустым, печатаем пустую строку
- `n` до 200000

Примеры:

- `10 20 30 40 50` (`n=5`, середина 2) → удаляем `30` → `10 20 40 50`
- `1 2 3 4` (`n=4`, середина 2) → удаляем `3` → `1 2 4`

## Алгоритм

Середину считать не надо искать двумя указателями: `n` уже известно.

1. `mid = n // 2`
2. Если `mid == 0` — удаляем голову, новая голова = `head.next`.
3. Иначе доходим до узла **перед** серединой (это `mid - 1` шагов) и перепрыгиваем средний:

```
cur.next = cur.next.next
```

Для `n=5`: `mid=2`, делаем 1 шаг от головы, стоим на `20`, режем `30`.

```
10 → 20 → 30 → 40 → 50
10 → 20 ──────→ 40 → 50
```

## Код

- `delete_middle(head, n)` — `n` передаём, потому что длина уже есть со входа.
- `n // 2` — в Python это как «разделить и отбросить дробь».
- Цикл `for _ in range(mid - 1)` — просто идём на `mid-1` узлов вперёд.
- Удаление всегда одно и то же: перекинуть `next` через соседа.
- Печать: если голова стала `None`, `' '.join([])` даст пустую строку — это как раз случай `n=1`.
