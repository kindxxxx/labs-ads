# E. Delete the Middle Node

## Условие

Список из `n` бегунов, индексы `0 … n-1` от головы. Нужно удалить «пейсмейкера» — узел с номером `⌊n / 2⌋`.

- `1 ≤ n ≤ 2·10^5`
- если `n = 1`, список станет пустым — напечатать пустую строку

## Идея

Середина известна сразу: `mid = n // 2` (целочисленное деление вниз).

Достаточно дойти до узла **перед** серединой и перекинуть `next` через средний узел.

Если `mid == 0` (список из одного элемента) — новая голова это `head.next` (то есть `None`).

## Алгоритм

1. Построить односвязный список.
2. `mid = n // 2`
3. Если `mid == 0` — вернуть `head.next`.
4. Иначе пройти `mid - 1` шаг от головы, затем `cur.next = cur.next.next`.
5. Вывести оставшиеся значения через пробел.

## Сложность

- время: `O(n)`
- память: `O(1)` дополнительно

## Примеры

`n = 5`, список `10 20 30 40 50`, `⌊5/2⌋ = 2` → удаляем `30` → `10 20 40 50`

`n = 4`, список `1 2 3 4`, `⌊4/2⌋ = 2` → удаляем `3` → `1 2 4`

`n = 1` → пустая строка
