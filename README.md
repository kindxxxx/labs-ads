# labs-ads

Репозиторий лабораторных по ADS (Algorithms & Data Structures).

## Структура

```
lab-02/
  a/          # задача A
    a.py              # решение
    a.md              # короткий конспект
    explanation.md    # конспект для тетради
  b/
  ...
  j/
lab-03/       # следующие лабы — по тому же шаблону
lab-service/  # Telegram-сервис заказов лабораторных (ADS/PP1/PP2)
```

Каждая задача лежит в своей папке: код и конспекты рядом.

## Как добавлять новую лабу

1. Создай `lab-NN/`
2. Для каждой задачи — папка `a/`, `b/`, … с `x.py`, `x.md`, `explanation.md`
3. Закоммить и запушь
